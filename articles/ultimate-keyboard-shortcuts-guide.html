🖥️ میانبرهای عمومی و مدیریت ویندوز

Ctrl + C

Ctrl + V

Ctrl + X

Ctrl + Z

Ctrl + A
انتخاب همه متن‌ها یا فایل‌های درون پوشه
Alt + F4

Win + D

Win + L

🌐 میانبرهای مرورگر وب و اینترنت

Ctrl + T
باز کردن تب (صفحه) جدید در مرورگر
Ctrl + W

Ctrl + Shift + T

Ctrl + R یا F5

Ctrl + J
